# Emertxe Projects

A collection of assignments and projects completed during the Emertxe training program, organized by subject.

## Repository Structure

| Folder | Contents |
|---|---|
| `01-C-Programming/` | C programming assignments and projects |
| `02-Data-Structures-and-Algorithms/` | Data structures and algorithms |
| `03-Microcontrollers/` | Embedded / microcontroller work |
| `04-Linux-Internals/` | Linux system programming and shell work |

Each folder has an `assignments/` and a `projects/` subfolder.

## Projects

| Project | Description | Tech |
|---|---|---|
| [LSB Image Steganography](01-C-Programming/projects/lsb-image-steganography) | Hide and extract a secret file inside a BMP image | C, bitwise ops, file I/O |
| [Inverted Search](02-Data-Structures-and-Algorithms/projects/inverted-search) | Build and search an inverted index database from text files | C, hash table, linked lists, file I/O |
| [Car Black Box](03-Microcontrollers/projects/car-black-box) | Vehicle event recorder firmware for a PIC microcontroller | Embedded C, PIC18F4580, I2C, ADC, UART |
| [Mini Shell](04-Linux-Internals/projects/mini-shell) | A custom command-line shell for Linux | C, processes, system calls |
